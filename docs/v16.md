# V16 compatibility decision

Status: accepted for this topic branch.

Context: Frappe Cloud requires a compatible app branch for the V16 major-version upgrade.

Decision: target V16 only on this branch, with Python 3.14 and bounded framework dependencies. Existing V15 development branches remain unchanged.

This branch targets Frappe V16 and Python 3.14. Use matching ERPNext and HRMS major versions where the app depends on them. Existing V15 branches remain separate; do not deploy this branch to a V15 bench.

Before production deployment, rehearse an upgrade of a recent site copy with outbound integrations disabled. Verify the app-specific workflows and the site-level Client Scripts, Server Scripts, Property Setters and print formats. Passing app tests does not validate database customizations outside this repository.

Validation on 28 October 2026 used Frappe 16.54.0, ERPNext 16.53.0, HRMS 16.52.0, Python 3.14 and Node 24. All app modules imported and a wheel built successfully. The isolated test site uses synthetic data; this is not a restored production-backup rehearsal.

Notification actions attach to the V16 sidebar lifecycle. Python unit tests and the sidebar JavaScript regression test pass.
